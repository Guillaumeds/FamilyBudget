# Wallet Budget Companion

This project has been renamed **Wallet Budget Companion** and is being rebuilt from scratch as a Cloudflare Worker (TypeScript + D1 + Cron Triggers) that adds real budget tracking, a small web dashboard and a daily WhatsApp brief on top of BudgetBakers Wallet. The rebuild is in progress, so setup instructions will land here once it is usable; the original Google Apps Script proof of concept lives in [`legacy/`](legacy/) for reference.
